前 言
================================================================================

1 本制度的目的在于建立健全华诚综合产业集团合规管理体系，明确合规管理原则、组织职责、运行机制与保障手段，统筹集团多业态（装备制造、国际贸易、技术服务、产业投资）合规风险，保障集团及全体员工、利益相关方的行为符合法律法规、监管规定、行业准则、商业惯例、企业内部规章制度以及国际条约和境外经营所在地法律要求。
2 本制度依据《中央企业合规管理办法》《企业境外经营合规管理指引》《合规管理体系 要求及使用指南》（GB/T 35770—2022）等法规标准，结合集团跨国经营、合规要求高的特点编制而成。
3 本制度既用于指导和规范集团总部及下属企业的合规管理工作，也作为对下属企业合规管理状况考核、合规责任追究的依据。
4 下属企业可参考本制度，结合自身行业特点与所在国（地区）法律环境制定细化的合规管理实施细则，但不得与本制度的基本原则和基本要求相冲突，细化细则须报集团法务合规部备案。
5 本制度需要逐步完善，由集团法务合规部负责解释与修订。在经营管理过程中，下属企业可提出书面修改建议和补充完善建议，报集团法务合规部。
6 本制度自发布之日起执行，原有相关规定与本制度不一致的，以本制度为准。

第一部分 合规管理基本要求
================================================================================

1 合规管理基本原则
1.1 全面覆盖原则。将合规要求嵌入公司治理、战略规划、投资决策、采购销售、财务资金、人力资源、境外经营等各领域、各环节，贯穿决策、执行、监督全流程，实现合规管理对所有业务、所有机构、所有岗位、所有员工的覆盖。
1.2 强化责任原则。集团及下属企业主要负责人（董事长、总经理）为本单位合规管理第一责任人；合规管理实行"谁主管、谁负责，谁审批、谁负责"，业务及职能部门承担合规主体责任。
1.3 协同联动原则。合规管理与法务、内控、风险、审计、纪检监察、财务、人力资源等职能协同衔接，建立信息互通、措施互补、成果互用的工作机制，避免重复管理和监管真空。
1.4 客观独立原则。合规管理机构和合规管理员独立履行职责，严格依照法律法规和企业制度对违规行为提出否定意见，不受其他部门和人员的不当干预；合规考核评价与工作经费予以保障。
1.5 风险导向原则。结合集团四大业态特点与国际经营环境，聚焦制裁、出口管制、反贿赂、反垄断、反洗钱、数据合规等重点领域和高风险环节，集中资源防控重大合规风险。

2 合规管理目标
2.1 底线目标：杜绝因违法违规行为导致重大行政处罚、刑事追究、被列入制裁或受限方清单、重大资产损失、声誉严重受损等合规红线事件。
2.2 管理目标：建立职责清晰、运转有效的合规管理组织体系，形成"事前预防、事中管控、事后整改"的闭环运行机制，重大经营决策、重要制度、重要合同合规审查覆盖率达到100%。
2.3 战略目标：培育全员合规、主动合规的文化，将合规要求转化为集团核心竞争力，支撑跨国经营行稳致远，保障年营收约350亿元、总资产约600亿元的稳健运营。

3 合规基本概念与术语
3.1 合规：指企业经营管理行为和员工履职行为符合国家法律法规、监管规定、行业准则和国际条约、规则，以及企业依法制定的章程、规章制度等要求。
3.2 合规风险：指企业及其员工因不合规行为，引发法律责任、受到相关处罚、造成经济或声誉损失以及其他负面影响的可能性。
3.3 合规义务：指企业应强制遵守的要求（法定义务）和自愿遵守的要求（如行业准则、商业惯例、企业承诺等）。
3.4 合规管理体系：为有效防控合规风险，提升依法合规经营管理水平而建立的一套包括机构、职责、制度、流程、工具、文化在内的管理体系。

4 合规管理依据与体系框架
4.1 外部依据：包括《中华人民共和国公司法》《中华人民共和国反不正当竞争法》《中华人民共和国反垄断法》《中华人民共和国出口管制法》《中华人民共和国反洗钱法》《中华人民共和国数据安全法》《中华人民共和国个人信息保护法》《阻断外国法律与措施不当域外适用办法》《中华人民共和国反外国制裁法》等国内法律法规，以及境外经营所在国（地区）相关法律、国际条约和制裁/出口管制规则。
4.2 内部框架：以本制度为统领，以合规义务清单、合规风险库为基础，以合规审查、风险预警、培训文化、举报调查、问责整改、境外与专项合规为主干，以配套办法为支撑，构建"1+N"合规管理制度体系。

第二部分 合规管理组织与职责
================================================================================

第一章 合规管理三道防线
1 第一道防线（业务及职能部门）
1.1 各业务及职能部门、各下属企业是合规风险防范的第一道防线，承担合规管理主体责任。
1.2 职责包括：在职责范围内识别、评估、防控本领域的合规风险；建立健全本领域合规管理流程和内控制度；在经营活动中主动履行合规审查前置程序；组织或配合合规培训；及时报告合规风险事件。
1.3 部门负责人为本部门合规管理直接责任人，应指定合规联络员对接法务合规部。

2 第二道防线（合规管理牵头部门）
2.1 集团法务合规部是合规管理牵头部门，承担合规管理综合协调和归口管理职责，构成第二道防线。
2.2 职责包括：组织起草、修订合规管理制度；牵头建立并维护合规义务清单和合规风险库；组织制度、重大决策、重要合同的合规审查；开展合规风险监测、预警与报告；组织合规培训与文化活动；受理合规咨询与违规举报；指导、监督、评价下属企业合规管理；统筹协调境外经营与专项合规。
2.3 首席合规官领导法务合规部开展工作，对重大合规事项直接向合规委员会和董事长报告。

3 第三道防线（监督部门）
3.1 内部审计、纪检监察、巡视巡察等监督部门构成第三道防线，独立开展合规管理有效性审计和监督执纪。
3.2 职责包括：对合规管理体系的设计与运行有效性进行独立审计评价；对违规问题开展执纪审查和追责调查；向合规委员会和董事会通报审计、监督发现的重大合规缺陷。
3.3 三道防线建立定期联席会议机制，由法务合规部每季度组织，通报风险、共享信息、协同整改。

第二章 合规委员会
1 设立与组成
1.1 集团设立合规委员会，作为合规管理的领导与决策机构，在董事会领导下开展工作。
1.2 合规委员会由董事长任主任，总经理、首席合规官任副主任，成员包括分管财务、投资、国际贸易、人力资源、审计、纪检监察的集团领导及法务合规部、战略部、国际业务部负责人。
1.3 合规委员会下设办公室，设在法务合规部，由首席合规官兼任办公室主任，负责日常事务。

2 主要职责
2.1 审议批准集团合规管理战略、规划、基本制度和年度合规工作计划。
2.2 审议批准合规义务清单、重大合规风险库及风险应对策略。
2.3 听取首席合规官关于合规管理状况、重大合规风险事件及整改情况的报告。
2.4 研究决定重大合规事项的处置方案，包括是否启动合规调查、是否向监管机构报告、是否作出合规问责决定。
2.5 统筹协调跨板块、跨区域的重大合规问题，推动境外经营合规管理。
2.6 对下属企业合规管理状况进行考核评价。

3 议事规则
3.1 合规委员会每半年至少召开一次全体会议；遇重大合规风险事件可临时召开。
3.2 会议由主任或受委托的副主任召集并主持，三分之二以上成员出席方可召开，决议须经到会成员过半数同意。
3.3 会议形成纪要，重大事项决策报董事会备案；合规委员会办公室负责督办决议执行。

第三章 首席合规官与合规管理员
1 首席合规官
1.1 集团设立首席合规官（可由总法律顾问兼任），由董事会任命，对董事会负责，领导法务合规部。
1.2 任职条件：具备法律、合规或相关专业高级以上职称或同等专业能力，熟悉集团四大业态及国际经营合规要求，具有八年以上相关工作经验，无违法违规不良记录。
1.3 主要职责：
（1）组织拟定合规管理战略规划、基本制度和年度计划；
（2）领导法务合规部履行第二道防线职责；
（3）对重大决策、重要制度、重要合同提出合规审查意见，拥有一票否决建议权；
（4）牵头应对重大合规风险事件，组织合规调查；
（5）向合规委员会、董事会及董事长报告合规重大事项；
（6）组织合规管理队伍建设和合规文化建设。
1.4 首席合规官应当保持独立性，不受违规决策干预；对经提醒仍坚持违规的决策，有权并应当记录、留存并向董事会或上级合规管理牵头部门报告。

2 合规管理员（合规专员）
2.1 下属企业及集团各业务板块（装备制造、国际贸易、技术服务、产业投资）应设立合规管理员，作为本单位、本板块合规管理的专（兼）职岗，接受法务合规部业务指导。
2.2 主要职责：
（1）负责本单位合规义务识别与风险信息收集，及时更新合规风险库；
（2）组织本单位制度、决策、合同的合规初审并报送法务合规部复审；
（3）开展合规培训、合规承诺签署与合规文化宣贯；
（4）受理本单位合规咨询与违规线索，按要求上报；
（5）跟踪本单位合规整改事项闭环。
2.3 国际贸易、产业投资等涉外板块合规管理员应具备相应外语能力和境外合规知识。

3 任职条件与任免
3.1 合规管理员应具备法律、财务、审计或业务专业背景，熟悉本单位业务和适用法规，通过集团组织的合规管理培训并考核合格。
3.2 合规管理员由本单位推荐、法务合规部审核、本单位负责人任命，任免情况报法务合规部备案；关键下属企业合规管理员任免应征求首席合规官意见。
3.3 合规管理员在同一单位连续任职一般不超过五年，到期轮岗，以保证独立性与客观性。

第三部分 合规义务清单与合规风险库
================================================================================

1 合规义务识别
1.1 法务合规部每年组织一次全集团合规义务识别，各业务及职能部门、下属企业配合，按照"业务—行为—适用规则"路径，系统梳理各业态各环节应遵守的合规义务。
1.2 识别范围覆盖：通用合规义务（公司治理、劳动用工、税务、环境保护、安全生产、反商业贿赂等）、业态专项义务（装备制造产品质量、国际贸易管制、技术服务知识产权、产业投资国资监管等）、境外经营义务（制裁、出口管制、当地数据保护、反贿赂等）。
1.3 当法律法规、监管政策或业务模式发生重大变化时，应在变化发生后30日内启动专项识别。

2 合规义务清单
2.1 在识别基础上建立集团《合规义务清单》，作为合规管理的基准依据。
2.2 清单要素包括：业务领域、合规义务名称、义务来源（法律法规/监管规定/行业准则/企业制度/国际规则）、适用主体、义务要求摘要、违反后果、责任部门、更新日期。
2.3 《合规义务清单》由法务合规部统一编制、维护，经首席合规官审核、合规委员会批准后发布，每年至少更新一次。
2.4 清单样（节选）：
┌────────┬──────────┬──────────────┬────────┬─────────────┐
│ 业务领域 │ 合规义务   │ 义务来源       │ 适用主体 │ 违反后果    │
├────────┼──────────┼──────────────┼────────┼─────────────┤
│ 国际贸易 │ 出口管制合规 │ 《出口管制法》 │ 国际业务部 │ 罚款/停业/清单 │
│ 反贿赂  │ 禁止商业贿赂 │ 《反不正当竞争法》│ 全员   │ 处罚/刑事责任  │
│ 数据    │ 个人信息保护 │ 《个人信息保护法》│ 全员   │ 处罚/赔偿    │
└────────┴──────────┴──────────────┴────────┴─────────────┘

3 合规风险识别与评估
3.1 在合规义务清单基础上，结合历史违规事件、监管处罚案例、业务变化与外部环境因素，识别合规风险点。
3.2 评估采用"可能性×后果严重性"二维模型，可能性分高、中、低三级，后果严重性分重大、较大、一般三级。
3.3 对跨境支付、受限方交易、政府关系、重大并购、数据出境等高风险场景，应在业务启动前开展专项合规风险评估，形成评估报告。

4 合规风险库
4.1 建立集团《合规风险库》，对识别评估的风险点实行清单化、动态化管理。
4.2 风险库要素包括：风险编号、风险名称、所属领域、风险描述、触发场景、风险等级、管控措施、责任部门、监测指标、更新日期。
4.3 风险等级划分：
（1）重大风险（红色）：可能导致集团被制裁、重大行政处罚、刑事追究、特别重大损失或声誉危机，须由合规委员会直接管控；
（2）较大风险（橙色）：可能导致较重处罚、较大损失，由法务合规部重点监控；
（3）一般风险（黄色）：由业务部门和合规管理员日常管控。
4.4 法务合规部负责风险库的日常维护，重大变化及时报告首席合规官。

5 合规风险管控措施
5.1 对每一项合规风险制定管控措施，明确责任部门、流程节点、控制要求和留痕方式。
5.2 将关键管控措施嵌入信息系统（如ERP、合同管理系统、贸易合规系统），实现系统硬控制。
5.3 对重大风险设置监测指标和预警阈值，纳入合规风险预警机制（见第五部分）。

第四部分 制度、决策与合同合规审查
================================================================================

1 制度合规审查
1.1 集团及下属企业制定、修订涉及经营管理的重要规章制度，须进行合规审查。
1.2 审查范围：公司治理、投资管理、采购与招标、销售与贸易、财务资金、人力资源、安全生产、境外经营、数据管理等领域的制度。
1.3 审查内容：制度是否符合法律法规和监管规定；是否与其他制度冲突；是否遗漏强制性合规要求；是否设定了必要的合规管控节点；境外适用制度是否符合当地法律。
1.4 流程：制度起草部门在征求意见阶段将草案及起草说明送法务合规部（或合规管理员初审后转报），法务合规部在5个工作日内出具《合规审查意见表》；审查通过后方可提交决策会议审议，审查意见作为上会必备材料。

2 重大决策合规审查
2.1 下列重大决策事项须经合规审查：
（1）重大投资、并购、合资合作及境外投资项目；
（2）重大资产处置、产权转让；
（3）重大融资、担保及关联交易；
（4）涉及制裁、出口管制、反垄断申报的事项；
（5）其他合规委员会认定的重大经营决策。
2.2 审查内容：决策事项适用的合规义务；是否存在制裁受限方、垄断、反腐败等合规障碍；需履行的申报、许可、备案程序；境外投资所在地的法律限制。
2.3 首席合规官对重大决策出具合规审查意见，意见为否定或附条件通过的，决策会议应予以充分审议；未经合规审查或审查未通过的，不得提交决策。

3 重要合同合规审查
3.1 下列合同须经合规审查：投资并购协议、合资合作协议、重大采购与销售合同、国际贸易合同、技术许可与转让合同、融资与担保合同、境外工程与咨询服务合同，以及金额或影响重大的其他合同。
3.2 审查内容：合同主体是否受限方或被制裁实体；交易标的与目的地是否受出口管制；付款路径与币种是否触发反洗钱或制裁风险；反贿赂与合规承诺条款是否齐备；争议解决与适用法律条款是否适当；数据跨境与知识产权条款是否合规。
3.3 合同承办部门在签署前将合同文本及背景资料送审，法务合规部在3—5个工作日内出具意见；涉外重大合同应开展受限方筛查并留存记录。

4 审查流程与时限
4.1 一般事项合规审查时限不超过5个工作日；重大、复杂事项可延长至10个工作日，并书面告知送审部门。
4.2 审查实行分级：下属企业合规管理员初审→法务合规部复审→首席合规官审签（重大事项）。境外合同须经国际业务合规专员会签。
4.3 送审材料应包括：事项说明、相关背景、草案文本、前置审批文件、其他必要资料；《合规审查送审单》样：

  合规审查送审单
  送审部门：____________  送审人：______  日期：______
  审查事项：□制度 □重大决策 □重要合同 □其他：______
  事项简述：__________________________________________
  合规风险自评：______________________________________
  附件清单：__________________________________________
  法务合规部意见：□通过 □附条件通过 □不予通过
  审查人：______  首席合规官：______  日期：______

5 审查意见与整改
5.1 审查意见分为"通过""附条件通过""不予通过"三类，均应书面载明理由与依据。
5.2 对"附条件通过"事项，送审部门须按条件完成整改并复验后方可推进；对"不予通过"事项，不得实施，须调整方案后重新送审。
5.3 合规审查意见、送审材料、整改记录由法务合规部归档保存，保存期不少于合同或事项存续期加十年。

第五部分 合规风险识别、评估与预警
================================================================================

1 风险识别机制
1.1 建立"日常+专项+年度"相结合的合规风险识别机制。
1.2 日常识别：业务部门和合规管理员在经营活动中实时识别风险，通过合规管理系统或月度合规报表上报。
1.3 专项识别：在新业务、新市场、新客户、重大交易、法律法规变化、监管处罚等情形发生后30日内，由法务合规部组织专项识别。
1.4 年度识别：每年末结合合规义务清单更新，开展全集团合规风险全面识别与重评。

2 风险评估方法
2.1 采用风险矩阵法，对识别的风险从可能性（高/中/低）与后果（重大/较大/一般）两个维度评定等级，形成风险热力图。
2.2 对制裁、出口管制、反贿赂、反垄断、数据出境等高影响风险，结合外部制裁名单、监管动态、行业案例进行情景分析。
2.3 评估结论纳入《合规风险库》，作为预警阈值设定和资源配置的依据。

3 风险预警机制
3.1 建立合规风险预警指标体系，对重大、较大风险设置定量或定性预警阈值。
3.2 预警指标示例：
（1）受限方/制裁名单命中（任何命中即红色预警）；
（2）单笔或累计异常大额交易、第三方代付等可疑交易线索；
（3）境外投资目的地法律环境重大恶化或遭制裁；
（4）监管问询、调查、处罚信息；
（5）重大合同违约或诉讼、仲裁；
（6）关键岗位人员涉腐、涉诉等。
3.3 预警信息来源：合规管理系统自动监测、外部法律资讯、监管通报、举报线索、审计报告、媒体舆情等。

4 预警分级与处置
4.1 预警分为三级：
（1）红色预警（重大）：立即由首席合规官报告合规委员会，24小时内启动应急，必要时暂停相关业务、冻结交易、向监管机构报告；
（2）橙色预警（较大）：由法务合规部牵头核查，5个工作日内形成处置方案并跟踪；
（3）黄色预警（一般）：由责任部门与合规管理员处置，报法务合规部备案。
4.2 预警处置实行闭环：预警触发→初步核实→风险评估→处置措施→整改落实→销号归档。处置情况纳入合规报告。
4.3 对同一风险重复触发预警的，应升级管控措施并纳入合规问责评估。

第六部分 合规培训与文化建设
================================================================================

1 培训体系
1.1 建立分层分类的合规培训体系：决策层侧重合规治理与责任；管理层侧重合规管理与风险管控；员工侧重岗位合规义务与行为规范；涉外人员侧重国际合规规则。
1.2 新员工入职须接受合规入职培训并签署《合规承诺书》后方可上岗；转岗、晋升人员须接受相应岗位合规培训。

2 培训计划与实施
2.1 法务合规部每年初制定年度合规培训计划，报首席合规官批准后实施。
2.2 培训频次要求：集团层面每年至少组织2次全员或骨干合规培训；涉外板块每年至少1次制裁/出口管制/反贿赂专项培训；下属企业每年至少1次全员合规培训。
2.3 培训形式包括：集中授课、案例研讨、在线学习、合规测试、情景演练等。关键岗位人员年度合规培训学时不少于8学时。
2.4 培训内容突出实操：合规义务清单与岗位风险、合规审查流程、举报与保护、受限方筛查、礼品招待、数据保护、境外合规红线等。
2.5 培训应保留签到表、课件、考核记录，作为合规履职证据归档。

3 合规文化建设
3.1 集团倡导"合规创造价值、违规零容忍"的文化，将合规理念融入企业价值观和行为准则。
3.2 通过合规宣传月、合规手册、合规专栏、典型案例通报、一把手讲合规等活动，营造全员合规氛围。
3.3 将合规要求写入员工手册和岗位职责，作为员工行为基本遵循。

4 合规承诺
4.1 全体员工每年签署《合规承诺书》，承诺遵守法律法规和企业合规制度，主动报告合规风险，不参与任何违法违规行为。
4.2 董事、高管、关键岗位（采购、销售、财务、国际贸易、投资、人事）人员须额外签署专项合规承诺，包括反贿赂、避免利益冲突、数据保护等。
4.3 商业伙伴（供应商、经销商、代理商、顾问）在合作前须签署《商业伙伴合规承诺函》，承诺遵守反贿赂等合规要求。

第七部分 违规举报、调查与问责整改
================================================================================

1 违规举报
1.1 集团建立"信、访、网、电"多渠道举报体系，设立专用举报邮箱、举报电话和线上举报平台，由法务合规部归口管理。
1.2 任何单位、员工及利益相关方均有权对涉嫌违规的行为进行举报，举报范围包括：商业贿赂、制裁违规、出口管制违规、垄断行为、洗钱线索、数据违规、利益冲突、弄虚作假等。
1.3 举报应提倡实名，同时保护匿名举报；举报人应对举报内容的真实性负责，不得诬告陷害。

2 举报受理与保护
2.1 法务合规部设立举报台账，对举报统一登记、编号、分类，5个工作日内决定是否受理并启动初步核实。
2.2 严格保护举报人：对举报人信息保密，严禁泄露；对打击报复举报人的，依规依纪严肃问责；经查证属实的举报，给予举报人适当奖励。
2.3 对匿名举报线索清晰、可查性强的，应当受理并核查。
2.4 举报登记表样：
  举报编号：______  受理日期：______
  举报方式：□邮箱 □电话 □平台 □来访 □其他
  被举报对象：________________________
  举报事项摘要：______________________
  初步核实结论：□受理核查 □转办 □不属实结案
  承办人：______  保密级别：______

3 合规调查
3.1 对受理的违规线索，由法务合规部牵头或会同审计、纪检监察部门开展合规调查，必要时聘请外部律师、会计师协助。
3.2 调查应遵循客观、公正、保密原则，依法收集书证、物证、电子数据、证人证言等证据，形成《合规调查报告》。
3.3 调查权限：经首席合规官批准后，可调阅相关文件资料、约谈相关人员、要求说明情况；被调查单位和个人应予配合，不得隐瞒、阻挠。
3.4 涉嫌违纪违法或犯罪的，按规定移送纪检监察或司法机关处理。

4 合规问责
4.1 对查实的违规行为，依据《员工违规处理办法》《违规经营投资责任追究办法》等，区分直接责任、主管责任、领导责任进行问责。
4.2 问责方式包括：警示谈话、通报批评、调离岗位、降职降级、解聘、追偿损失、移送追责等；构成违法犯罪的，依法追究法律责任。
4.3 问责决定由合规委员会或其授权机构作出，人力资源部门执行；问责情况纳入个人绩效考核与诚信档案。
4.4 对违规决策坚持"上追一级"，单位主要负责人对本单位重大违规承担领导责任。

5 整改与闭环
5.1 针对调查发现的合规缺陷，由法务合规部制发《合规整改通知书》，明确整改事项、责任部门、整改措施和完成时限。
5.2 责任部门应制定整改方案并限期落实，法务合规部跟踪验收，整改完成方可销号。
5.3 对普遍性问题，应推动完善制度、流程和系统控制，防止同类问题再次发生；整改情况纳入合规考核与年度报告。

第八部分 境外经营合规管理
================================================================================

第一章 制裁与出口管制合规
1 制裁合规
1.1 集团及下属企业开展境外经营、国际贸易、跨境资金业务，须遵守联合国、我国及交易相关国（地区）的制裁法律法规，重点防范美国OFAC、欧盟、联合国制裁清单等域外适用风险。
1.2 建立受限方筛查机制：在客户、供应商、合作伙伴准入及每笔交易前，通过制裁名单筛查系统对交易对方、最终用户、承运人、受益人进行筛查；任何命中须立即冻结交易并报告法务合规部。
1.3 制裁名单包括：联合国制裁名单、我国外交部/商务部制裁与管控名单、美国OFAC SDN清单、欧盟限制性措施清单及其他适用司法管辖区清单。名单每周更新，遇重大变动即时更新。
1.4 对位于或涉及受全面制裁国家/地区的业务，原则上不予开展；确需开展的，须事先完成全面合规评估并经合规委员会批准。

2 出口管制合规
2.1 涉及装备制造成套设备、军民两用物项、技术、软件出口及转口贸易的，须遵守《中华人民共和国出口管制法》及目的地国出口管制规则（如美国EAR）。
2.2 建立出口物项分类与许可管理制度：对出口物项进行ECCN/管制分类，判断是否需要出口许可证；未取得许可不得出口。
2.3 履行最终用户与最终用途审核：要求境外买方提供最终用户和最终用途声明，核实是否涉及军事、扩散等敏感用途，必要时开展实地核查。
2.4 建立出口管制合规档案，保存交易文件、许可、筛查与审核记录，保存期不少于十年，满足监管追溯要求。

3 清单筛查与记录
3.1 受限方筛查应覆盖"了解你的客户（KYC）"全流程，留存筛查时间、版本、命中情况及处置记录。
3.2 对"50%规则"等间接持股受控实体，应通过股权穿透识别，防止变相与受限方交易。
3.3 跨境支付环节，银行报文（如SWIFT）信息须与筛查结果一致，禁止通过第三国、第三方拆分绕开制裁。

第二章 境外反贿赂与反腐败合规
1 反贿赂政策
1.1 集团及全体员工、商业伙伴在境外经营中严格遵守《反不正当竞争法》《刑法》及适用司法管辖区反贿赂法律（如美国FCPA、英国UKBA、经合组织反贿赂公约），禁止为获取或保有业务向任何公职人员或商业相对方给付、承诺或授权给付不当利益。
1.2 禁止以任何形式向外国公职人员提供贿赂；对"公职人员"作广义解释，包括政府官员、国企管理人员、国际组织官员及其亲属。

2 礼品与招待
2.1 建立礼品招待审批与限额制度：向客户或公职人员提供礼品、招待、差旅、赞助须事前审批，价值不得超过集团规定限额，且不得具有不当影响决策的性质。
2.2 单次礼品招待金额超过规定标准的，须经合规管理员审核、分管领导批准；对公职人员的任何礼品招待均须首席合规官批准。
2.3 所有礼品招待应登记留存，定期复核，防止演变为商业贿赂。

3 第三方尽职调查
3.1 对境外代理商、经销商、顾问、分包商、中介机构等第三方，在合作前开展合规尽职调查，评估其背景、关联关系、合规记录与贿赂风险。
3.2 与第三方签署反贿赂条款和《商业伙伴合规承诺函》，约定审计权、违约终止权；对高风险第三方提高尽职调查频度并加强交易监控。
3.3 禁止通过第三方变相输送利益；第三方费用应真实、合理并有成果交付，留存服务协议与成果报告。

4 政治敏感人物（PEP）管理
4.1 对交易对方、受益人、实际控制人属于政治敏感人物（含其亲属密切关联方）的，提高尽调等级，须经首席合规官审批。
4.2 建立PEP名单，动态维护，相关交易纳入重点监控。

第九部分 专项合规管理
================================================================================

第一章 反垄断合规
1 垄断协议防控
1.1 禁止与竞争者达成横向垄断协议（固定价格、限制产量、分割市场、联合抵制等）或纵向垄断协议（转售价格维持等），法律法规另有规定的除外。
1.2 在行业协会活动、与竞争者交流中，严禁交换敏感商业信息（价格、产能、客户、投标意向等）；参会人员应遵守反垄断合规指引并留存记录。
1.3 与竞争对手的合资、合作、标准制定、研发安排，须经法务合规部反垄断审查。

2 滥用市场支配地位防控
2.1 在装备制造、产业投资等具有市场优势的板块，禁止实施不公平高价、低价倾销、拒绝交易、限定交易、搭售、差别待遇等滥用行为。
2.2 市场支配地位的认定与风险评估由法务合规部结合市场份额、市场控制力分析进行，必要时外部法律意见支持。

3 经营者集中申报
3.1 达到《国务院关于经营者集中申报标准的规定》阈值的并购、新设合营、控制权变更等，须事前向反垄断执法机构申报，未获批准不得实施（停表期不得交割）。
3.2 法务合规部建立经营者集中台账，在交易筹划阶段即介入，判断申报义务、准备申报材料、跟踪审查进度。
3.3 境外并购还须评估交易各司法管辖区的反垄断申报义务，统筹全球申报策略。

第二章 反洗钱合规
1 客户身份识别（KYC）
1.1 集团金融、国际贸易、产业投资等涉及资金往来板块，应建立客户身份识别制度，在建立业务关系、办理规定金额以上交易时核实客户身份，了解受益所有人和交易目的。
1.2 对高风险客户（跨境、现金密集、PEP、受制裁关联）强化尽职调查，必要时提高监控等级或拒绝交易。

2 大额与可疑交易报告
2.1 严格执行《中华人民共和国反洗钱法》（2024年修订，2025年施行）要求，对大额交易和可疑交易按规定监测、分析并报告中国反洗钱监测分析中心。
2.2 可疑情形包括：交易与客户身份、经营规模明显不符；频繁大额现金或第三方代付；资金快进快出无合理商业目的；与高风险地区/受限方关联等。
2.3 建立反洗钱交易监测指标和模型，由专人复核，杜绝屡查屡犯。

3 制裁名单监控与记录保存
3.1 将反洗钱与客户筛查、制裁名单监控结合，发现命中或可疑立即冻结并报法务合规部。
3.2 客户身份资料、交易记录保存至少十年，配合监管与司法查询。

第三章 数据合规
1 数据分类分级
1.1 依据《数据安全法》《个人信息保护法》，建立数据分类分级制度，将数据分为一般数据、重要数据、核心数据，对个人信息按敏感程度分级。
1.2 不同级别数据采取差异化保护措施，重要数据、核心数据及敏感个人信息实行更严格的访问、加密、审计管控。

2 个人信息保护
2.1 处理个人信息应遵循合法、正当、必要和诚信原则，取得同意或具备其他合法性基础，履行告知义务，最小必要收集。
2.2 建立个人信息影响评估（PIA）制度，对自动化决策、委托处理、公开、对外提供等高风险处理活动事前评估。
2.3 员工、客户、供应商个人信息处理须设专人负责，防止泄露、篡改、丢失。

3 数据出境合规
3.1 集团及下属企业向境外提供重要数据、个人信息，须按《数据出境安全评估办法》《个人信息出境标准合同办法》等履行评估、备案或认证程序。
3.2 数据出境前由法务合规部会同信息部门审查出境必要性、接收方保护能力与合同条款，完成合规手续后方可传输。
3.3 关键信息基础设施运营者及达阈值处理者，重要数据出境须通过国家网信部门安全评估。

第十部分 合规报告与考核
================================================================================

1 合规报告
1.1 建立"定期+专项"合规报告制度。
1.2 定期报告：下属企业合规管理员每月编报《合规月报》；法务合规部每季度编报《合规季度报告》；每年末编报《年度合规管理报告》。
1.3 定期报告内容：合规义务清单与风险库更新情况、合规审查统计、风险预警与处置、培训与文化、举报调查与问责、境外与专项合规状况、存在问题和改进计划。
1.4 专项报告：发生重大合规风险事件、被监管调查处罚、触发红色预警、境外重大合规事项，应在24小时内口头报告、5个工作日内书面专项报告首席合规官和合规委员会，并按监管要求对外报告。
1.5 年度合规管理报告经合规委员会审议后，向董事会报告，并按国资监管等要求报送上级单位。

2 合规考核
2.1 将合规管理纳入集团对下属企业和负责人的绩效考核，权重不低于年度综合考核的10%。
2.2 考核指标包括：合规审查覆盖率（目标100%）、合规培训完成率、风险预警处置及时率、整改闭环率、违规事件发生率、合规文化达标率等。
2.3 考核方式：日常监测、年度自评、法务合规部复核、合规委员会审定，结合审计与监督发现综合评定。

3 考核结果运用
3.1 考核结果与单位评优、负责人薪酬、晋升挂钩；考核不合格的单位，责令整改并约谈负责人。
3.2 因合规管理不到位导致重大违规事件或损失的，在考核中实行"一票否决"，并追究相关人员责任。
3.3 对合规管理成效突出的单位和个人，给予表彰和奖励，纳入合规文化建设正向激励。

第十一部分 配套制度和规定
================================================================================

第一章 合规义务清单管理办法
为规范合规义务识别、清单编制与动态维护，制定本办法。
一、职责：法务合规部归口管理，各业务部门、下属企业配合提供本领域义务信息。
二、识别频率：每年度全面识别一次；法律法规或业务重大变化后30日内专项识别。
三、清单要素：业务领域、义务名称、来源、适用主体、要求摘要、违反后果、责任部门、更新日期（见第三部分2.4样表）。
四、审批与发布：清单经首席合规官审核、合规委员会批准后发布，作为合规审查与培训基准。
五、维护：法务合规部设专岗维护，任何更新留痕可溯，保存期不少于十年。

第二章 合规审查工作办法
为规范制度、重大决策、重要合同合规审查，制定本办法。
一、审查分级：下属企业合规管理员初审→法务合规部复审→首席合规官审签（重大）。
二、送审材料：送审单、事项说明、草案文本、前置审批及背景资料，材料不全退回补正。
三、时限：一般5个工作日，重大复杂10个工作日，涉外重大合同须完成受限方筛查。
四、意见类别：通过/附条件通过/不予通过，书面载明依据；附条件通过须整改复验，不予通过不得实施。
五、归档：审查意见、送审材料、整改记录由法务合规部归档，保存期不少于事项存续期加十年。

第三章 违规举报管理办法
为规范违规举报受理、保护与核查，制定本办法。
一、渠道：专用邮箱、电话、线上平台、来访，由法务合规部归口，统一登记编号。
二、受理：5个工作日内决定是否受理；匿名但线索清晰可查的应予核查。
三、保护：严格保密举报人信息，禁止打击报复，查证属实给予奖励。
四、调查：法务合规部牵头，必要时会同审计、纪检监察或外聘专业机构；被调查方须配合。
五、处置：查实依规问责，制发整改通知，闭环验收；涉违法犯罪的移送有权机关。

第四章 境外经营合规管理办法
为规范境外经营制裁、出口管制、反贿赂及数据等合规，制定本办法。
一、适用：集团及下属企业全部境外投资、贸易、工程、服务及跨境资金业务。
二、受限方筛查：客户、供应商、最终用户、承运人、受益人准入及每笔交易前必筛，命中即冻结并报告。
三、出口管制：物项分类、许可管理、最终用户与用途审核、档案保存十年以上。
四、反贿赂：礼品招待限额审批，第三方尽职调查和承诺函，PEP强化管理。
五、数据出境：按国内法履行评估、备案或认证，境外数据须满足当地保护要求。
六、应急：触发境外制裁或重大合规事件，24小时内报告首席合规官，必要时暂停业务、寻求法律意见并向监管报告。
