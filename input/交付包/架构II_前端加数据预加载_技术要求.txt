架构II：前端 + 数据预加载 JSON — 技术要求
================================

1. 定位与适用场景
---------------------------------
- 适用于需要内置结构化数据（词典、样本、配置），但无需实时后端的应用。
- 典型：知识库面板、离线检索、示例驱动的研究 / 教学辅助工具。

2. 启动与运行方式
---------------------------------
- 交付物：index.html（数据可内联，或随包提供 data/*.json）。
- 启动：双击 index.html，浏览器直接打开并运行。
- 无需安装依赖、无需启动服务器、无需配置环境。

3. 技术要求
---------------------------------
- 所有 CSS / JS 内联或通过 HTTPS CDN 加载，确保应用可共享、可移植。
- 预加载数据以 JSON 提供；为保证 file:// 双击即开，推荐将 JSON 内联进 HTML
  （如 const DATA = {...}），避免浏览器在 file:// 下拦截本地文件读取。
- 若 JSON 以独立文件随包提供，须明确说明：file:// 下浏览器禁止 fetch 本地文件，
  必须经本地服务器托管，或改为内联，否则数据加载失败。
- 数据规模较大时，内联会增大单文件体积，属可接受的离线代价。

4. 约束与边界
---------------------------------
- 数据为静态、预生成，不支持实时更新；更新需重新生成 / 替换 JSON 并重建页面。
- 同样受 file:// 沙箱与 CORS 限制（见架构I）。
- 大模型能力（如需要）同架构I处理。

5. 验收要点
---------------------------------
- 双击即开，内置数据可用，检索 / 筛选 / 面板交互正常。
- 迁移整个文件夹后功能不丢失。
- 数据更新流程已文档化。
